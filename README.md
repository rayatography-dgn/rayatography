## 🌟 Highlights

- **Selective Glassmorphism**: Refined, transparent glass cards and badges with subtle blur and edge illumination.
- **Behance Project Showcase**: Curated case study exhibition featuring top 6 featured works with high-res thumbnails and dynamic modal deep-dives.
- **Editorial Bento Grid**: 8 Core capabilities with synchronized typography and interactive indicators.
- **Official Brand Integration**: Custom vector brand logo with signature crimson accents.

---

## 🛠️ Tech Stack

- **Semantic HTML5** & **Vanilla Modern CSS** (Zero heavy UI framework bloat).
- **Vanilla JavaScript (ES6+)** with requestAnimationFrame scroll interpolation.
- **Custom HTML5 Canvas** frame rendering pipeline with preloading buffer.

## 🚀 Running Locally

To run the local development server:

```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```

Then visit [http://localhost:3000/](http://localhost:3000/) in your browser.
